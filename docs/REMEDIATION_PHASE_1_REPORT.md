## 4. Dependency Security Assessment & Minimal Compatible Update

### Baseline Vulnerability Status
Initial audit reported:
- **`esbuild <= 0.24.2`** (Moderate, [GHSA-67mh-4wv8-2f99](https://github.com/advisories/GHSA-67mh-4wv8-2f99)): Dev server request hijacking.
- **`tinypool <= 2.1.1`** (Critical, [GHSA-5gmw-xhrv-c9v3](https://github.com/advisories/GHSA-5gmw-xhrv-c9v3) / [GHSA-85c8-ppgw-ccpr](https://github.com/advisories/GHSA-85c8-ppgw-ccpr)): Prototype pollution leading to RCE in worker options.

### Minimal Compatible Remediation Applied
Rather than running destructive `npm audit fix --force` (which attempts to upgrade to `vite@8.3.5`, breaking the React plugin and bundler compatibility), we applied **targeted package overrides** in [`package.json`](file:///media/sda3/Projects/Calibration/package.json):
```json
"overrides": {
  "esbuild": "^0.25.0",
  "tinypool": "^2.1.2"
}
```
- **Result:**
  - `esbuild` upgraded cleanly from `0.21.5` to `0.25.12`.
  - `tinypool` upgraded cleanly from `0.8.4` to `2.2.0`.
  - **Both the `esbuild` dev-server vulnerability and the `tinypool` Critical RCE vulnerability were eliminated.**

### Remaining Advisory
- **`vite <= 6.4.3`** (High): Relates to path traversal in optimized `.map` dependencies and Windows launch-editor escaping. Because the project is currently built on Vite 5 (`vite@5.4.21`), resolving this requires upgrading to Vite 6+, which is a major version jump. We recommend scheduling the Vite 6 migration for a dedicated infrastructure phase after local persistence is delivered.
